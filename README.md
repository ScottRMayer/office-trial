# Office system — trial build

A single-page office and field app: the appointment book, the calling loop, render sheets,
the daily close, pre-scheduled program letters, warranties, and WDI (NPMA-33) reports.

**This repository contains the application only — no customer data.**
The sample names, addresses and phone numbers in it are invented for testing.

## How the data works

Everything you enter stays **in the browser on the device you enter it on**. Nothing is
uploaded to this repository or anywhere else. There is no server and no account.

- Two devices do not share data yet. Each keeps its own.
- Use **Data → Export backup** regularly. That backup file contains real customer
  information — keep it somewhere safe and **never add it to this repository**.
- **Data → Reset to sample data** clears the device and puts the demo data back.

## Running it

Open the published page, or open `index.html` directly from a folder. It works with no
internet connection once loaded.

On an iPad: open the page in Safari, then **Share → Add to Home Screen** to get an icon
that opens full-screen.

## Note for the trial

Browsers can clear stored data if a site goes unused for a long stretch, so during the
trial export a backup at the end of any day that matters.
